# 프로젝트 개요

## 프로젝트 이름

Boss Timer · Item Auction · Settlement System

## 목표

게임 길드/그룹 운영에 필요한 세 가지 기능을 하나의 시스템으로 구축합니다.

1. 보스타이머
2. 아이템 경매
3. 정산 시스템

핵심 원칙은 **현재 단계가 완전히 구현되고 검증된 뒤에만 다음 단계로 이동하는 것**입니다.

## 개발 순서

### 0단계 — 개발 기록 환경

- GitHub 저장소
- 개발 일지
- 개인 블로그
- Reddit 진행 기록

### 1단계 — 보스타이머

예정 기능:

- 로그인 / 사용자 관리
- 그룹 또는 길드 관리
- 보스 등록 / 수정 / 삭제
- 리젠 시간 설정
- 보스 처치 시간 기록
- 다음 출현 시간 자동 계산
- 실시간 남은 시간 표시
- 여러 사용자의 실시간 상태 동기화
- 알림
- 작업자 기록 / 변경 이력
- 서버 재시작 후 정상 복구
- 백업 및 기본 모니터링

### 2단계 — 아이템 경매

보스타이머가 완료된 후 설계합니다.

예정 흐름:

```text
아이템 등록
→ 경매 시작
→ 입찰
→ 최고가 실시간 갱신
→ 경매 종료
→ 낙찰
→ 거래 기록
```

### 3단계 — 정산 시스템

아이템 경매가 완료된 후 설계합니다.

예정 흐름:

```text
보스 참여 기록
+ 아이템 판매 금액
+ 정산 규칙
→ 개인별 정산 내역
```

## 인프라 원칙

가능한 한 보유 중인 Always Free / Free Tier 자원을 활용합니다.

- OCI AMD Compute 2대
- OCI DB 2개
- GCP Compute 1대
- Cloudflare Free
- Supabase
- Firebase
- MongoDB
- Neon
- AWS Free Tier
- Azure Free Tier

단, 무료 서비스를 많이 사용하는 것 자체를 목표로 하지 않습니다. 각 서비스에는 명확한 역할이 생겼을 때만 연결합니다.

## 초보자 학습 원칙

이 프로젝트에서는 결과만 만드는 것이 아니라 다음 내용도 함께 익힙니다.

- Git / GitHub
- Linux 기본 명령어
- SSH
- Docker
- DNS / HTTPS
- Cloudflare
- 웹 Frontend / Backend
- Database
- API
- 실시간 통신
- 보안 기본기
- 백업과 모니터링

모든 단계는 가능하면 `확인 → 실행 → 결과 확인 → 기록` 순서로 진행합니다.

## 보안 원칙

공개 저장소이므로 다음 값은 절대 커밋하지 않습니다.

- 비밀번호
- 실제 `.env`
- API Key / Token
- SSH Private Key
- Database Connection String의 실제 자격 증명
- JWT Secret
- Cloudflare Tunnel Token

## 완료 기준

각 단계는 단순히 코드를 작성했다고 완료되지 않습니다.

실제 환경에서 정상 동작하고, 재시작/오류 상황을 포함한 기본 테스트가 끝나며, 문서까지 기록한 후 완료 처리합니다.
