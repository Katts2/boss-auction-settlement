# GitHub Learning

GitHub를 직접 사용하면서 배운 내용을 기록합니다.

## Repository

프로젝트의 파일과 변경 기록을 저장하는 공간입니다.

## File

프로젝트를 구성하는 하나의 파일입니다.

예:

- README.md
- .gitignore
- package.json

## Folder

여러 파일을 정리해서 보관하는 공간입니다.

예:

```text
docs/
├── github-learning.md
├── 00-project-overview.md
└── 01-development-log.md
