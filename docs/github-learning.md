# GitHub Learning

GitHub를 직접 사용하면서 배운 내용을 기록합니다.

## Repository

프로젝트의 파일과 변경 기록을 저장하는 공간입니다.

## File

프로젝트를 구성하는 하나의 파일입니다.

예:

- README.md
- .gitignore
- package.json

## Folder

여러 파일을 정리해서 보관하는 공간입니다.

예:

```text
docs/
├── github-learning.md
├── 00-project-overview.md
└── 01-development-log.md
```

## Commit

파일의 변경 사항을 하나의 저장 지점으로 기록합니다.

## 현재 배운 것

- Repository 만들기
- README 수정하기
- Markdown 작성하기
- Commit 만들기
- Commit History 확인하기
- 폴더와 파일 만들기

## 다음에 배울 것

- Git Clone
- Git Add
- Git Commit
- Git Push
- Git Pull
- Branch

## Local Git

GitHub 웹사이트가 아니라 내 컴퓨터에서 Git을 사용하기 시작했습니다.

### 배운 명령어

- git clone
- git status
